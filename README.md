## Installation and Usage

1. **Clone this repository**:
   ```bash
   git clone https://github.com/anortef/protofy-packer.git
   cd protofy-packer
2. **Initialize Packer plugins (if using a modern .pkr.hcl workflow)**:
   ```bash
   packer init .
4. **Build the OVA**:
   ```bash
   packer build .
## Importing the OVA in VirtualBox

1. Open VirtualBox.
2. Go to File > Import Appliance....
3. Select the .ova file generated by the build.
4. Follow the on-screen instructions to import the appliance.
5. Start the newly imported virtual machine.
